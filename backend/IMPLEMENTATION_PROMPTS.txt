## STAGE 3: PAGES MODEL & CONTENT STORAGE (JSON-BASED FLEXIBLE STORAGE)
### Goal: Pages can belong to ANY group or subgroup. Store content in structured JSON + text. Clean text output on fetch.

PROMPT 3.1 - Pages Model with JSON Content Storage
"""
Design pages to hold content. Key requirement: "The data is to be stored postgresql DB in json format... any of these group or subgroups can have content page where the data in text format would be displayed. so we need to make the db accordingly, also the json format data saved in the db would be fetched and outputed as clean text"

Model Page:
```python
Page:
  id: UUID PK
  group_id: UUID FK -> groups.id (NOT NULL) - belongs to exactly one group/subgroup
  title: str
  slug: str (unique per lang? or globally; support translations later)
  lang: str default 'en' (en/hr/tr/ar)
  status: enum('draft','pending','published','rejected') default 'draft'
  content: JSONB NOT NULL (primary structured storage) - see structure below
  content_text: TEXT nullable (denormalized clean/plain text for search/display/export)
  excerpt: TEXT nullable
  is_homepage: bool default False
  featured: bool default False
  author_id, last_edited_by_id, submitted_by_id, approved_by_id: FK users
  reject_note: text nullable
  # live snapshot for published
  live_title, live_slug, live_content(JSONB), live_content_text
  # meta
  meta_title, meta_description, meta_keywords (JSONB or text)
  position: int default 0
  published_at: datetime nullable
  created_at, updated_at
```

Suggested content JSON structure:
```json
{
  "blocks": [
    {"type": "heading", "level": 2, "text": "..."},
    {"type": "paragraph", "text": "..."},
    {"type": "list", "ordered": false, "items": ["..."]},
    {"type": "image", "src": "...", "alt": "..."},
    {"type": "quote", "text": "...", "cite": "..."},
    {"type": "callout", "variant": "info", "text": "..."}
  ],
  "format": "blocks-v1",
  "source": "richtext" // or "markdown"
}
```

But also support simple "body" field inside content. 
Service: generate clean text from content (strip HTML, extract all text nodes from blocks) and store in content_text on save/update. Also compute on read if missing.

Add indexes: (group_id), (slug, lang), (status), (is_homepage).
Unique constraint: (slug, lang).

Migration included.
"""

PROMPT 3.2 - Content Text Extraction Service
"""
Create app/services/content_text.py

Function extract_clean_text(content: dict | None) -> str:
- If content is None return ""
- Extract text from common structures:
  - content["body"] (HTML or plain) -> strip tags if HTML
  - content["text"] 
  - content["blocks"] -> concatenate block.text, items etc
  - also handle "sections", "fields" patterns
- Strip extra whitespace, newlines collapsed
- Return clean UTF-8 string

Also add HTML stripper (use html.parser or bleach.clean with strip=True).

Use this in CRUD create/update: set content_text = extract_clean_text(obj_in.content)

Add unit test.
"""
